05 / 08
Security & Technical Quality

มาตรการความปลอดภัยและคุณภาพทางเทคนิค (Week 10)

Security Certified
✓

Password Hashing & Session

เข้ารหัสรหัสผ่านด้วย bcrypt.hash(..., 10) ไม่มีเก็บ plain text และใช้ JWT ใน HTTP-only Secure Cookie ป้องกันการขโมย Token ผ่าน XSS

✓

SQL Injection & XSS Prevention

ใช้ Prisma Parameterized Queries 100% ปราศจาก Raw SQL ที่เสี่ยงต่อ SQLi และไม่ใช้ `dangerouslySetInnerHTML` กับข้อมูลจากผู้ใช้

✓

Zod Schema Validation

ตรวจสอบรูปแบบ Email, ความยาว Password, ช่วงคะแนนรีวิว (1-5) และ Body ทุก Endpoint ก่อนเข้าสู่ฐานข้อมูล

✓

Authorization & IDOR Protection

ตรวจสอบสิทธิ์ว่า User เป็นเจ้าของรีวิว/Watchlist จริงหรือไม่ก่อนทำ Mutation และแยกระดับสิทธิ์ USER vs ADMIN อย่างเคร่งครัด

OWASP Standard Web Security
